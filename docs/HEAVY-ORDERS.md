# Грузоперевозки и спецтехника на Order

Новые cargo/freight и equipment заказы используют то же ядро v1, журнал и серверную машину состояний, что такси и доставка. Старые engine_version=0 продолжают прежний сценарий. Миграция 013 расширяет типы присутствия исполнителей и добавляет демонстрационные тарифы; действующие заказы не переписываются.

## Два способа поиска

- **Автопоиск по фиксированной цене**: координаты маршрута груза или места работы, машина, параметры, дата/время, расчёт цены и подтверждение. Фоновый worker выбирает ближайшего подходящего исполнителя по прямой, предлагает заказ на 45 секунд, расширяет радиус 2 → 5 → 8 км. Для будущих заказов поиск начинается за 20 минут; это не гарантия заблаговременного бронирования машины. Через час после времени подачи поиск прекращается.
- **Предложения цены для сложного заказа**: прежняя лента с публичным кратким описанием, предложения за весь заказ и выбор заказчиком. Выбор записывает offered → accepted в одной транзакции и сохраняет согласованные условия. Это оффер исполнителя, поэтому повторное принятие им не требуется. Ручные отклики запрещены для автоматических заказов.

Оба варианта после назначения: «Еду к заказчику» → «Я прибыл» → код начала от заказчика → выполнение → подтверждение заказчиком → отзыв. Отказ до начала возвращает поиск; после начала отмена запрещена. Общая занятость исключает одновременное назначение с такси/доставкой. Споры сохраняют прежние ограничения.

## Цена и параметры

Тарифы находятся в `order_tariffs`, привязаны к услуге, типу машины и версии. Груз: base + perKm × расстояние по прямой. Техника: base + perHour × выбранная длительность; минимум и округление берутся из правил. API возвращает полный расчёт до подтверждения, создание повторно сверяет цену/версию. `price_snapshot` сохраняет правила, длительность, цену и валюту UZS. Изменение тарифа не меняет существующий заказ.

Почасовой расчёт — фиксированная сумма за согласованное число часов, без автоматического счётчика дополнительных часов. В ручном режиме цена — итог предложения за весь заказ; снимок сохраняет длительность и комментарий. Тарифы демонстрационные, не исследованные рыночные ставки. Реальные платежи, чеки и выплаты не подключены.

Фильтры: точный тип машины, подтверждённая личность, активная собственная машина, свежий GPS, грузоподъёмность для грузов; для крана — масса подъёма и вылет стрелы. Подтверждение квалификации остаётся существующей декларацией исполнителя, а не новой внешней проверкой документов. Габариты/условия доступа задаются описанием; автоматического фильтра по габаритам, грузчиков, фотографий объекта и сменного тарифа в этом релизе нет.

## API и интерфейс

`POST /api/mobility/quote` принимает kind=cargo|equipment, vehicleKind, origin, destination (cargo), durationHours (equipment). `create` дополнен matchingMode=auto|offers (по умолчанию offers для совместимости), quotedTariffVersion. Автоматический режим требует координаты.

`POST /api/mobility/presence` принимает прежние поля GPS/машины и kind=taxi|cargo|equipment; `GET /api/mobility/presence?kind=…` возвращает входящие только этой услуги. Прежние клиенты без kind продолжают работать с taxi. Поле online=false отключает только выбранную услугу. При принятии повторно сверяются параметры, свежесть и та же машина, которой был предложен заказ.

Кабинет исполнителя содержит отдельный выход на линию для каждой услуги. На экране заказа — карта точек и свежей позиции машины, SSE статусов плюс резервное обновление каждые 7 секунд (включая предложения цены). Точные координаты видят участники; после завершения/устаревания GPS маркер скрыт. Мобильный браузер не гарантирует GPS в фоне.

## Rollout и проверка

`HEAVY_CORE_ENABLED=false` оставляет новые ручные заказы на прежнем обработчике и запрещает создание новых автоматических. Уже созданные v1 продолжают обслуживаться. Не откатывать образ к версии, не знающей v1 heavy, пока есть активные такие заказы; использовать флаг на текущей версии. Перед миграцией production нужна актуальная резервная копия.

Демо: добавьте кран в «Исполнителям → Спецтехника → Мои машины», разрешите GPS и выйдите на линию. Вторым аккаунтом создайте заказ, выберите автопоиск, место работы, нужный подъём/вылет и 2 часа. Рассчитайте цену, подтвердите, первым аккаунтом примите входящий заказ и пройдите этапы с кодом. Отдельно проверьте режим предложений цены. Аналогичный автопоиск доступен грузовым машинам с A→B и массой груза.
