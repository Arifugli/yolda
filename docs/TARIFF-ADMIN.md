# Управление тарифами машин

Администратор открывает профиль → «Администрирование» → «Тарифы машин». Доступны действующие тарифы такси, грузовых машин и спецтехники, их параметры и предыдущие версии. Для изменения — «Изменить тариф», числовые поля, обязательная причина и «Сохранить новую версию». Денежные значения указаны в сумах. Доставка пока сохраняет прежние настройки в «Тарифы и зоны»; этот редактор их не меняет.

Сохранение создаёт новую активную версию и оставляет прежние правила в истории. Изменение применяется к будущим заказам, цена существующего Order хранится в price_snapshot и не пересчитывается. Если клиент рассчитал цену до изменения тарифа, сервер при подтверждении проверит сумму/версию и попросит пересчитать стоимость. Запланированный уже созданный заказ также сохраняет свой снимок.

Сервер разрешает чтение/запись только роли admin, повторно проверяет роль/ограничения при мутации. Указанная в форме expectedVersion защищает от потери правок при работе двух администраторов. Конкурирующие записи сериализуются на уровне тарифа, проверка версии и смена active выполняются в одной транзакции. Повтор с тем же Idempotency-Key возвращает результат без следующей версии; другое тело с прежним ключом отклоняется.

В audit_logs сохраняются actor_id, tariff.update, услуга, код, предыдущая/новая версии, прежние/новые правила и причина. Ошибка откатывает весь переход. Старые версии нельзя редактировать через API. Возврат к прежней цене: перенести её значения в новую версию; отдельной команды удаления истории или выключения тарифа нет.

API:
- GET /api/admin/tariffs — действующие и предыдущие тарифы (до 500 записей).
- POST /api/admin.tariff с Idempotency-Key: serviceType (ride|freight|equipment), code, expectedVersion, reason и rules. Редактор меняет только существующий активный тариф; создание новых видов услуг через этот API не предусмотрено.
- rules: base, perKm, minimum, roundTo, maxKm; для грузов/техники также perHour. У грузов perHour=0, у техники perKm=0. Для техники maxKm сохраняется, но не участвует в почасовой цене. Проверяются положительные лимиты, отсутствие неизвестных полей и максимально возможная сумма ≤ 1 000 000 000 сум.

Новых миграций, секретов или платных сервисов нет. Тарифы остаются демонстрационными до отдельного согласования ставок. Реальные платежи/чеки/выплаты этим редактором не подключаются.
